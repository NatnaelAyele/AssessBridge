# Safe Exam Browser configuration

`AssessBridge.seb` is a generic password-encrypted configuration for older local invitations. New invitations store their own encrypted configuration and Config Key in PostgreSQL, and their email contains an HTTP(S) launch-page link with an **Open in SEB** action. The server checks the invitation's Config Key at entry and on every exam API request. Current SEB on macOS supplies this key through its JavaScript API; older clients may send the native request header.

To use it locally:

1. Restart Uvicorn after the `.env` update.
2. Install a current Safe Exam Browser client on the candidate computer.
3. In a regular browser, register and verify the invitation email before opening SEB. Open the normal HTTP(S) exam launch page linked in the invitation, then select **Open in Safe Exam Browser**. If the browser does not launch SEB, download the `.seb` file from that page. Enter the configuration password from the invitation.
4. Sign in with the candidate's verified email and account password, then enter the separate exam-only credentials. The candidate may exit SEB at any stage. Exiting before **Start exam** has no exam consequence; exiting after **Start exam** and before submission disqualifies that attempt. The active-exam exit action tries to record the choice, then opens the configured SEB quit link even if the API fails. A new sign-in also disqualifies an active attempt immediately; the server disqualifies it if the 10-second heartbeat is absent for 45 seconds before the deadline. After submission, select **Exit exam** without disqualification.

New invitation configurations use an eight-character invitation-specific configuration password and emergency quit code included in that email. The generic `AssessBridge.seb` file still uses `SEB_CONFIG_PASSWORD` and `SEB_QUIT_PASSWORD` from `.env` and is only for older local invitations. Existing invitation files retain their original passwords. A native SEB quit cannot synchronously notify FastAPI. A new sign-in disqualifies an active attempt immediately; otherwise the server infers a quit from missing heartbeats. A 45-second outage during the exam, or a missing heartbeat near the deadline, can therefore disqualify a candidate. A quit in the final seconds may still be indistinguishable from an ordinary timeout. The installed Windows SEB 3.10.2 library successfully decrypted and parsed the generic file and calculated the same Config Key as the server; the full interactive SEB flow still needs device testing.

For deployment, run `python backend/make_seb_config.py --base-url https://your-exam-host`, set `COOKIE_SECURE=true`, update `EXAM_ENTRY_URL`, and restart the server. New invitations will then store exam-specific configurations for the public URL. This script regenerates only the generic configuration; previously stored invitation configurations keep their original start URLs and must be rebuilt and redistributed separately. Test the generated files in actual SEB on Windows and macOS before candidate use.
